POLARIS

A fixed point amid motion. Visual studies of discovery, construction, and changing environments.

01 / The concept

Always
in motion.

POLARIS is an installation concept that explores humanity's continuing pursuit of discovery, construction, and movement.

Developed through TouchDesigner and traditional illustration, the proposal brings together generative visuals, fisheye perspectives, and data visualization. Its shifting environments move between urban landscapes, ocean waves, natural formations, and ascending staircases, with Polaris serving as a fixed reference point amid change. The concept proposes population and tidal data as inputs for evolving visuals, alongside microphone-based audience interaction. Proposed presentation formats include a circular screen and a spatial installation using existing screens.

Proposed interaction

The proposal outlines microphone input as a way for audiences to influence visual elements in real time. A speaker system would provide background music, while a workstation would run the visual scenes. These elements describe the planned experience.
